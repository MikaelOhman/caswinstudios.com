Saltmere: Privacy policy

Last updated: 6 November 2026

Saltmere is made by CasWin Studios, Sweden.

  • Saltmere does not collect, store, share or sell any personal data.
  • The game has no accounts, no ads, no analytics and no tracking.
  • The game does not ask for internet access and does not send anything off your device.
  • Your saved games and settings are stored only on your device, in the game's own storage. Uninstalling the game deletes them.
  • The game does not use your location, contacts, camera, microphone or any other personal information.
  • The game collects no information from anyone, including children.

Exporting a save

You can export a saved game as text or as a file, for example to move it to another phone. It only goes where you choose to send it, and it contains only the game's own data.

Links in the game

The Help and Map screens can open the Saltmere wiki on this website in your own web browser. If you email us, we only use your message and address to read and answer it.

Changes

If a future version changes any of this, this policy will be updated before that version is released.
