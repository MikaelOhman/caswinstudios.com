BrainQuest: Privacy policy

Last updated: 6 November 2026

BrainQuest is made by CasWin Studios, Sweden.

  • BrainQuest does not collect, share or sell any personal data.
  • BrainQuest is made for children. It has no accounts, no ads, no in-app purchases, no analytics and no tracking.
  • The app does not ask for internet access and does not send anything off the device.
  • Profiles (a first name or nickname, an avatar and an age), progress, settings and paintings are stored only on the device, in the app's own storage. Uninstalling the app deletes them.
  • The app does not use location, contacts or the camera.

The microphone

Some reading tasks can listen to the child read aloud. The microphone is off by default; only a parent can turn it on, in the parent area. Speech is recognised on the device itself. The recording lives only in the device's memory for at most 12 seconds, is never saved and never leaves the device, and is thrown away as soon as it has been checked. Without the microphone, an adult taps how the reading went instead.

Adaptation settings

The app never asks for or stores a diagnosis. It stores only the settings a parent chooses, such as text size or calmer animations.

Backups

A parent can export a backup file of the profiles and progress, for example to move them to a new device. It only goes where the parent chooses to save or send it.

Children

No information is collected from children or anyone else. If you email us, we only use your message and address to read and answer it.

Changes

If a future version changes any of this, this policy will be updated before that version is released.
